Формули з лекції «Цінова стратегія фірми»
Витратні методи (Блок 4):

• Ціна беззбитковості: P = AVC + FC / Q

• Витрати плюс: P = ATC × (1 + m)

• Цільовий прибуток: P = AVC + (FC + π_ціл) / Q

• Нижня межа ціни (модель 3C): у короткостроковому періоді P ≥ AVC, у довгостроковому P ≥ ATC (де ATC = AVC + FC / Q).

• Безповоротні (sunk) витрати не враховуються!

Ринкова влада та Олігополія (Блок 2):

• Правило націнки: P* = MC × E / (1 + E)

• Індекс Лернера: L = (P - MC) / P = -1 / E

• Оптимальна націнка на MC: m* = -1 / (1 + E)

Дискримінація і Тендер (Блоки 4, 5):

• Очікуваний прибуток тендеру: (P - C) × Pr(перемоги)

• Дискримінація 3-го ст.: MR₁ = MR₂ = MC (вища ціна там, де |E| менший!)

• Для попиту P = a - b×Q граничний дохід має вдвічі крутіший нахил: MR = a - 2b×Q
